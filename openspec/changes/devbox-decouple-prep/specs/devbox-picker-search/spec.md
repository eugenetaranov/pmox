## MODIFIED Requirements

### Requirement: Registry snapshot
The pmox repository SHALL hold a snapshot of mise's registry (name, aliases, description per line) at `internal/bootstrap/mise-registry.tsv`, regenerated by the `bootstrap:mise-registry` task and by a weekly GitHub Action that uses the latest mise and commits the file to main when it changed. The Action SHALL NOT commit a snapshot with fewer than 500 rows. The full snapshot SHALL be installed at `/usr/local/share/devbox-setup/mise-registry.tsv`.

#### Scenario: Snapshot installed
- **WHEN** pmox installs devbox-setup's files on a VM
- **THEN** `mise-registry.tsv` with names, aliases and descriptions is written next to `picker.py`

#### Scenario: Weekly refresh
- **WHEN** the weekly workflow runs and mise's registry gained tools
- **THEN** main has a new `chore: refresh mise registry` commit that changes only `mise-registry.tsv`

#### Scenario: Broken upstream
- **WHEN** the regenerated snapshot has fewer than 500 rows
- **THEN** the workflow fails without committing
