## Context

The picker is a stdlib-only curses script (`picker.py`) fed a line file by `devbox-setup` and returning chosen ids. Letters other than `q` and digits do nothing today; "only space changes a selection" is deliberate. On a fresh VM mise is not installed when the picker first opens; devbox-setup installs it as a hidden helper.

## Goals / Non-Goals

**Goals:** find any catalog item or mise tool by typing a few letters; keep the picker dependency-free; work on the first run.

**Non-Goals:** version selection inside the picker (the existing prompt covers it); searching non-registry backends (`npm:`, `pipx:` …).

## Decisions

- **Type to search.** Any printable key except space edits the query, like fzf. Quitting moves to Esc (on an empty query) and Ctrl-C, since `q` types. Digits are tab shortcuts only with no query, so `k9s` can be typed.
- **Own scorer.** A subsequence scorer favouring exact/prefix name matches, then word starts, then runs, ties by shorter text; catalog before mise. ~1000 items rescored per key is instant in Python.
- **Registry source.** Live `mise registry -J --hide-aliased` when mise is present (current). Otherwise the full snapshot from the repo's `main` on GitHub (5 s timeout, cached a week in `/var/lib/devbox-setup`), else the embedded names-only copy. The full snapshot (~39 KB as gz+b64) does not fit: user-data was already ~53 KB of PVE's 64 KiB snippet limit; names only add ~6 KB. The snapshot is generated by a Taskfile task from the developer's mise, like `bootstrap:sync`, and lives beside `picker.py` because `bootstrap:sync` replaces `assets/`.
- **Display.** Double-width characters (emoji, CJK) and `:shortcode:` emoji are dropped from displayed descriptions, since the column layout counts characters. Subsequence matching applies to names and catalog labels only; descriptions and sources match as substrings, which keeps long descriptions from matching everything.
- **Dedupe in the picker.** picker.py already has each catalog item's source; it drops a registry row whose name appears as a tool in a catalog item's `mise use -g` source. One tool, one row.
- **Ids.** Registry picks come back as `mise:<short>`; devbox-setup moves them into `RUN_MISE_EXTRA`, which already drives `resolve`, `mise_use` and saved answers.

## Risks / Trade-offs

- [Snapshot goes stale] → live registry is preferred whenever mise exists; regenerate at release time.
- [No network on first run] → names-only search still works.
- [`q` no longer quits] → footer shows "esc quit"; Ctrl-C also quits.
